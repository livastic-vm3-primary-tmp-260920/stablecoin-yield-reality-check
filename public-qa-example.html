2. Findings that change interpretation

  • No reported reward component: The source explicitly reports 0% rewards; that is not proof of no future incentive change.
  • Reward-heavy headline: 39.1% of headline APY is reported as rewards; do not confuse incentives with the base component.
  • Missing reward breakdown: The source provided no rewards breakdown. Do not infer a zero incentive reward from a null field.

Fee break-even: base-only return becomes positive only after the hypothetical fees are covered. A higher headline APY does not remove risks or guarantee any reward token can be realized at its quoted value.

Missing values: an omitted reward field remains UNKNOWN; it is never automatically set to zero. Any real audit would need source-level investigation, not an assumption that reported values reflect available withdrawals.
